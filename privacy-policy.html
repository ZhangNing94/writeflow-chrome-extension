WriteFlow Privacy Policy

Last updated: May 13, 2026

1. Data Collection

WriteFlow collects minimal data and stores it locally on your device:

  • Settings & Preferences: Your selected rewrite mode (Formal/Simple/Creative/Academic), Pro license status, and optional API key are stored in Chrome's local storage (chrome.storage.local). None of this data is sent to our servers — we don't have servers.
  • Usage Counter: A daily counter of free rewrites used is stored locally to enforce the free tier limit. This counter resets daily.
  • Text Content: The text you type or select for rewriting is sent to the DeepSeek API solely for the purpose of generating rewritten output. WriteFlow does not log, store, or retain your text content on any server.

We do not collect: browsing history, personal identification information, cookies, IP addresses, or any analytics/tracking data.

2. Data Processing & Third-Party Services

WriteFlow uses one third-party service:

  • DeepSeek API (api.deepseek.com) — The text you submit for rewriting is transmitted to DeepSeek's API for AI-powered text generation. DeepSeek's privacy policy applies to data processed through their API: platform.deepseek.com/privacy.

When using the Pro license, license verification requests are sent to verify your 6-digit PIN. No personal information is associated with this verification.

3. Permission Justifications

WriteFlow requests the following Chrome permissions for specific functionality:

  • activeTab — Needed to read the text on your current tab for rewrites. WriteFlow only accesses the tab when you activate the extension (click the icon or use the right-click context menu).
  • storage — Used to save your preferences (mode selection, API key, Pro status) locally on your device. All data in chrome.storage.local stays on your computer.
  • contextMenus — Used to add a "Rewrite with WriteFlow" option to the right-click menu, allowing you to select and rewrite text on any page.
  • clipboardWrite — Used solely for the "Copy" button to copy rewritten text to your clipboard at your request.
  • scripting — Used to inject the rewrite result UI into the page when you use the right-click rewrite feature. Scripts are only injected on pages where you explicitly trigger a rewrite.
  • Host: api.deepseek.com — Required to send rewrite requests to the DeepSeek API. Only text you explicitly submit for rewriting is transmitted.

4. Your Rights & Control

  • Delete Your Data: All settings and stored data can be cleared by removing the extension or using the "Remove Key" button in Settings. WriteFlow stores nothing remotely.
  • Uninstall: Simply remove the extension from Chrome. No data persists after uninstallation.
  • Opt Out: If you prefer not to use the built-in AI, you can bring your own DeepSeek API Key in Settings. The built-in key is then bypassed.
  • No Account Required: WriteFlow works without signup, login, or any personal information.

5. Data Security

  • The built-in API key is obfuscated for security purposes. While no obfuscation is foolproof, this measure discourages casual extraction. Users who prefer full control can use their own API key in settings.
  • Your optional personal API key is stored in Chrome's encrypted local storage and never transmitted except to DeepSeek's API for text rewriting.
  • All communication with DeepSeek's API uses HTTPS.
  • WriteFlow does not use analytics, crash reporting, or any background data collection.
